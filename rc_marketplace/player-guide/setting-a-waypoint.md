# Setting a Waypoint

When an ad has a map pin, the full ad view shows a Leaflet map widget with the pinned location.

Click the **navigation-arrow icon** inside the map widget. This sets a waypoint marker on your minimap and the in-game GPS route pointing to the pinned coordinates.

There is no command or keybind for this — it is only accessible from the map widget on the ad view.

If an ad has no map pin (the poster typed a location manually without using the map picker or "Use my position"), the map widget is not shown and the waypoint button is not available.

The waypoint works identically in phone mode and standalone desktop mode.
