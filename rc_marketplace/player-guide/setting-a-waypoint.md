# Setting a Waypoint

When an ad has a map pin, the full ad view shows a Leaflet map widget with the pinned location.

In the corner of the map widget, click the **navigation-arrow icon**. This sets a waypoint marker on your minimap and the in-game GPS route at the pinned coordinates.

There is no command or keybind for this — it is only accessible from the map widget on the ad view.

If an ad has no map pin (the poster did not use the location picker or "Use current location"), the map widget is not shown and no waypoint button is available.

The waypoint works identically in phone mode and standalone desktop mode.
