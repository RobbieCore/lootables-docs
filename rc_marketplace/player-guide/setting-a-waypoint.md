# Setting a Waypoint

When an ad has a map pin, the full ad view shows a GTA V map widget with the pinned location.

Click the **Set waypoint** button in the map widget. This places a waypoint on your minimap and activates the GPS route pointing to the pinned coordinates.

There is no chat command or keybind for this — it is only accessible from the map widget on the ad view.

If an ad has no map pin (the poster typed a location manually without using the map picker or "Use my position"), the map widget is not shown and the waypoint button is not available.

The waypoint works identically in phone mode and standalone desktop mode.
